## 1. Commercial Thesis: The Anti-Subscription Fatigue Model

Operon is built on the reality of 2026: Knowledge workers and developers hate paying $10-$20/mo recurring subscriptions for desktop launchers and local utilities.

Because Operon is **local-first** and does NOT incur massive monthly per-user cloud GPU / API costs, we can offer an extraordinarily profitable, high-margin, and consumer-friendly pricing model.

## 2. Tier Breakdown

### 2.1 Free Tier ("Community Core")
- **Price:** $0 forever.
- **No account required.** No email required. No telemetry required.
- **Included Features:**
  - Unlimited execution of all 15 pre-installed core recipes.
  - Full desktop Global Quick Command HUD (`Alt+Space`).
  - Core Clipboard Utilities (read, write, clean formatting).
  - Basic File & Image Converters (single and small batches up to 10 files).
  - Standard dark themes (Graphite & OLED Black).
  - Local execution history (last 50 runs).
  - Tier 1 Deterministic Natural Language Parser.

### 2.2 Operon Pro ("Power & Studio")
- **Pricing Options:**
  - **Lifetime Pass:** $39 one-time (Single platform or full cross-platform bundle).
  - **Annual Pass:** $19/year (Includes all major version updates).
  - **Regional Pricing:** Discounted 40–60% in CIS, LatAm, India, and Southeast Asia.
- **Pro Features:**
  - Unlimited custom workflow creation & visual DAG editing.
  - Large-scale batch operations (>1000 files, recursive folders).
  - Developer Tool Pack (cURL-to-code, JSON Schema inference, RegEx sandbox, JWT tools).

  - Unlimited encrypted local clipboard & execution history.
  - Custom rice themes, custom CSS styling, and accent color pickers.
  - Future Peer-to-Peer End-to-End Encrypted Sync across devices.

## 3. CIS & Regional Payment Infrastructure
- **Global Markets (US, EU, UK, Asia):** Stripe, Apple In-App Purchase, Google Play Billing.
- **CIS & Russia Support:**
  - Standard Western credit cards cannot process Russian cards.
  - Architecture provides an abstract `IBillingProvider` supporting:
    - YooKassa / SBP (Faster Payments System) for Russian rubles.
    - Telegram Stars / Crypto (USDT on TON/TRC-20) for borderless checkout.
    - Apple App Store / Google Play where regional accounts are maintained.
- **Zero Mock Purchases:** The software clearly indicates billing mode (`Local Sandbox / Active License / Pro Key`) and never fabricates fake transactional success.
